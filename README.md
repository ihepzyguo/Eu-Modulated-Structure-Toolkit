Modulated-Structure Toolkit for Eu Metal

I have developed, with AI assistance, a modulated-structure toolkit based on the modulation function reported in Phys. Rev. Lett. 109, 095503 (2012) and Phys. Rev. B 90, 214105 (2014), to reproduce the modulated structure of Eu metal under high pressure.

If you use this toolkit in published work, please cite these two papers.
